## 0. Общие правила (основа для всего остального)

Чтобы всё приложение выглядело одинаково, вводим несколько "кирпичиков" и используем только их.

| Что | Значение | Где |
|-----|----------|-----|
| Отступ от краёв экрана | 16 dp | везде |
| Расстояние между карточками | 12 dp | везде |
| Скругление карточки | 24 dp | карточки-плашки (как в "Статистике") |
| Скругление элементов внутри карточки | 16 dp | кнопки, плитки, картинки |
| "Таблетка" (полностью круглые края) | 50% | поиск, переключатели "День / 7 дней", нижняя панель, чипы |
| Внутренний отступ карточки | 16 dp | везде |

**Карточка** — главный элемент. Всё, что на экране, лежит в карточках: список, настройки, графики.
Строки внутри одной карточки разделены тонкой линией или просто отступом, без рамок.
За образец берём вкладку "Статистика" — она уже такая, как нравится. 🟡

## 1. Нижняя панель как в Telegram 🟡

Сейчас панель — широкая полоса во всю ширину, прилипла к низу. В Telegram (твой скриншот) это отдельная
тёмная капсула над списком: по бокам и снизу видно содержимое, выбранная вкладка ("Чаты") — в своём
светлом кружке-таблетке зелёного цвета. Делаем так же:

```
                     содержимое экрана прокручивается ПОД панелью
   ╭───────────────────────────────────────────────────╮
   │  ╭─────────╮                                        │
   │  │  ▣ Apps │    ◎ Фокус     ▤ Статистика   ⚙ Наст.  │
   │  ╰─────────╯                                        │
   ╰───────────────────────────────────────────────────╯
        ↑ отступ 16 dp по бокам и ~12 dp снизу от края экрана
```

- Панель — отдельная "таблетка": отступы со всех сторон, полностью скруглённые края, лёгкая тень.
- Выбранная вкладка подсвечена своей маленькой таблеткой (фон чуть темнее / цвет акцента), иконка + подпись.
- Невыбранные — только иконка и подпись приглушённым цветом.
- Переход подсветки между вкладками — плавно "переезжает" (анимация ~250 мс).
- Список под панелью прокручивается дальше, чтобы последний пункт не прятался (внизу запас высоты панели).
- В обычном стиле: фон панели — непрозрачный цвет карточки. В стеклянном (п. 4) — размытое стекло.
- 💡 Лёгкая вибрация при переключении вкладки.

## 2. Создание PIN как в банковских приложениях 🟡

Сейчас PIN вводится в обычное текстовое поле с системной клавиатурой. Делаем как на твоём примере из банка:
крупный заголовок сверху, 4 точки посередине, большие цифры без рамок внизу, зелёная ссылка в самом низу.

```
        Здравствуйте, Егор           ← крупно, жирно
     Придумайте PIN-код              ← ниже, обычным шрифтом

            ●  ●  ○  ○               ← пустые: тёмно-серые кружки, заполненные: зелёные

        1         2         3
        4         5         6        ← крупные тонкие цифры, без кружков
        7         8         9
      Назад       0         ⌫        ← слева текст-действие, справа стереть

          PIN из 6 цифр              ← зелёная ссылка (как "Не можете войти?")
```

Отличия от банка:
- Справа внизу вместо отпечатка — "стереть" ⌫ (отпечаток не делаем, см. ниже).
- Слева внизу: при создании — "Назад" (к помощнику), при вводе — "Отмена".
- ✅ Внизу при вводе PIN — "Забыли PIN?" → объяснение: сбросить можно только удалив приложение
  (вместе с правилами). Так и задумано: иначе защита бессмысленна.

- **Шаг 1 "Придумайте PIN-код"** → после 4-й цифры сам переходит к шагу 2.
- **Шаг 2 "Повторите PIN-код"** → совпал: галочка, лёгкая вибрация, дальше в приложение.
  Не совпал: точки трясутся и краснеют, подпись "Коды не совпадают", снова шаг 1.
- Цифры — крупные (~36 sp), без рамки; при нажатии под цифрой на миг появляется светлый круг.
- Фон экрана — обычный фон темы (в тёмной — "ночной лес", в светлой — мятный), без карточек.
- Точки: пустые — кружок-контур, заполненные — цвет акцента, заполняются с маленькой анимацией.
- Длина: по умолчанию 4 цифры, ссылка "PIN из 6 цифр" под точками переключает на 6
  (так и в банках, и не нужно кнопки "Готово").
- Такая же клавиатура — везде, где сейчас спрашивается PIN (открыть правило, отменить фокус, разблокировать).
  Там заголовок "Введите PIN-код", снизу слева можно "Отмена".
- ✅ **Приветствие:** просто "Здравствуйте" (имя при первом запуске не спрашиваем).
  Взять имя из аккаунта Samsung/Google без вопросов нельзя: нужно разрешение на контакты/аккаунты,
  Google Play считает его "чувствительным" и требует объяснений — ради приветствия не стоит.
  💡 В Настройках можно сделать необязательное поле "Как к вам обращаться" → тогда "Здравствуйте, Егор".
- 💡 Входа по отпечатку пальца НЕ делаем: PIN защищает от самого себя, а палец приложить слишком легко.

## 3. Единая форма: карточки, скругления, поиск 🟡

### 3.1 Вкладка "Приложения"
- Сейчас поиск — прямоугольник с рамкой и почти острыми углами (выбивается из стиля).
- Станет таблеткой как в Telegram: полностью круглые края, без рамки, залит цветом карточки,
  слева лупа, справа крестик "очистить" (появляется, когда что-то введено). Высота ~52 dp.
- ✅ Две карточки: поменьше — "Заблокированные", побольше — "Все приложения" (как блоки в "Статистике").
  Заголовок раздела и кнопка сортировки — внутри карточки сверху, строки приложений — без изменений.

### 3.2 Вкладка "Фокус"
- Поиск — такой же таблетка, как в "Приложениях" (один общий компонент на оба экрана).

### 3.3 Вкладка "Статистика"
- Не трогаем, это образец (карточки "Сегодня", "По дням", "Чаще всего", переключатель-таблетка "День / 7 дней").

### 3.4 Вкладка "Настройки" — группы в отдельных карточках

```
 Настройки

 ╭─ Язык ────────────────────────────╮
 │ 🌐 Язык              Как в телефоне │
 ╰───────────────────────────────────╯

 ╭─ Защита ──────────────────────────╮
 │ 🔔 Постоянное уведомление     [ ● ] │
 │ ⏰ Предупреждать до блокировки  5 мин│
 │ 🎟 Пропуски в день                3 │
 │ 🔒 Сменить PIN-код                > │
 ╰───────────────────────────────────╯

 ╭─ Банк времени ────────────────────╮
 │ 🏦 Открыть банк                   > │
 │ 📅 Дни, когда можно тратить   Сб, Вс│
 │ ♻ Сгорает в понедельник       [ ● ] │
 │ ⛔ Тратить в блок-периоды (×3) [   ]│
 ╰───────────────────────────────────╯

 ╭─ Внешний вид ─────────────────────╮   ← новая группа
 │ 🎨 Тема          Как в телефоне   > │
 │ 💧 Стеклянный стиль            [   ]│
 ╰───────────────────────────────────╯

 ╭─ Батарея Samsung ─────────────────╮
 │ ✅ Работа в фоне разрешена          │
 │ Как настроить "Без ограничений"   > │
 ╰───────────────────────────────────╯

 ╭───────────────────────────────────╮
 │ 🛠 Дополнительно                  > │   ← "спрятанное"
 ╰───────────────────────────────────╯
```

- Заголовок группы — маленьким шрифтом цвета акцента над карточкой (или внутри сверху).
- У каждой строки слева иконка в маленьком скруглённом квадрате с бледным фоном (как в настройках iPhone/Samsung). 💡
- **Батарея Samsung** — своя карточка. Если всё уже разрешено, она сжимается до одной строки "✅ Работа в фоне разрешена".
- **Дополнительно** (отдельный экран, одна строка внизу): разрешения, "Пройти помощник заново",
  версия приложения, позже — политика конфиденциальности. Не на виду, но найти легко.
  Если какое-то обязательное разрешение пропало — наверху Настроек всё равно появляется красная плашка
  (как сейчас в "Приложениях"), чтобы человек не потерял защиту.

### 3.5 Остальные экраны (правило, банк, экран блокировки, помощник)
- Переводим на те же карточки и скругления. Кнопки — скруглённые 16 dp или таблетки, без острых углов.

## 4. Стеклянный стиль (Liquid Glass) 🟡

**Что это:** полупрозрачные элементы, сквозь которые видно размытое содержимое под ними
(как нижняя панель в Telegram на iPhone и вся система iOS 26).

### Где стекло
- Нижняя панель (главное).
- Верхняя панель с заголовком — при прокрутке становится стеклянной.
- Выбранная вкладка в панели — "капля" стекла чуть ярче.
- Всплывающие окна (PIN, диалоги) — фон за ними размывается.
- ✅ Карточки тоже пробуем стеклянными. Если текст будет плохо читаться или не понравится — вернём обычные.

### Android
- Настройки → Внешний вид → "Стеклянный стиль" (выключен по умолчанию).
- Выключен: всё как описано в п. 1–3, непрозрачные таблетки.
- Включён: те же формы, но панели — стекло: размытие фона ~20–30 dp, белый/тёмный слой ~60–70%,
  тонкая светлая обводка 1 dp, мягкая тень.
- Размытие "того, что под панелью" в Compose из коробки нет, понадобится библиотека (например, Haze)
  — проверю на этапе 13. На слабых телефонах может подтормаживать, поэтому и выключатель. minSdk 33 —
  нужные функции системы есть на всех поддерживаемых телефонах.

### iPhone
- Там стекло — стандарт системы (iOS 26), выключателя нет.
- ⚠ Важно: версия для iPhone — отдельный большой проект. Сейчас приложение на Kotlin только для Android,
  а блокировка на iPhone работает совсем иначе (Apple Screen Time API, другие правила, свои ограничения).
  Просто "перенести" не получится. Предлагаю пока делать Android, а iPhone обсудить после публикации в Google Play.

## 5. Светлая тема — переделать 🟡

**Проблема (видно на твоём скриншоте "Apps" в светлой теме):** фон почти белый (#F6FBF2), нижняя панель
серо-бежевая, подсветка выбранной вкладки едва заметна, зелёный текст бледный → всё сливается, "просто белое".

**Идея:** фон — отчётливо мятный, карточки — чисто белые. Тогда карточки "всплывают" над фоном, как в тёмной теме.

| Роль | Сейчас | Предлагаю |
|------|--------|-----------|
| Фон экрана | #F6FBF2 (почти белый) | **#E6F2EA** мятный (можно мягкий градиент сверху вниз #DDEFE4 → #EEF6F1) |
| Карточки | #EBEFE7 / #F0F5ED | **#FFFFFF** белые + тень 1–2 dp или обводка #D6E6DC |
| Основной цвет (кнопки, выбранное) | #3D6A4A | **#2E6B47** чуть глубже и сочнее |
| Светлый акцент (выбранная вкладка, чипы) | #BEEFC9 | **#CDEFD8** |
| Текст | #181D19 | #16211A (без изменений по сути) |
| Второстепенный текст | #414942 | #4F5F55 |
| Акцент "вода" (второй цвет графиков) | #3A656F | #2F7A86 |

Для стеклянного стиля в светлой теме: за содержимым — 2–3 больших очень размытых "пятна"
(мятное, бледно-бирюзовое, чуть-чуть персиковое), почти незаметные. Без них стеклу нечего размывать,
и оно выглядит как просто белая плашка. В обычном стиле пятна не нужны.

Тёмная тема "ночной лес" нравится — не трогаем, только проверим, что карточки и стекло в ней тоже выглядят хорошо.

## 6. Мои идеи 💡 (бери что нравится)

1. **Выбор темы в Настройках:** "Как в телефоне / Светлая / Тёмная" (сейчас только как в телефоне).
2. **Шапка вкладки "Приложения":** карточка "Сегодня 2 ч 14 мин" с кольцом прогресса к дневной цели
   и огоньком серии (связка с этапом 11). Сразу видно главное.
3. **Иконки в цветных квадратиках** в настройках и в строках правил — быстрее находить глазами.
4. **Экран блокировки спокойнее:** крупное время до разблокировки по центру, мягкая "дышащая" анимация
   круга (вдох-выдох 4 с), фраза-напоминание. Задача — успокоить, а не наказать.
5. **Пустые состояния:** когда нет правил / нет данных — маленькая картинка в стиле логотипа и одна фраза,
   а не пустой экран.
6. **Плавные переходы между экранами** (сдвиг + проявление), карточки появляются по очереди при открытии.
7. **Вибрация** (лёгкая) на цифрах PIN, переключателях и вкладках. Отключается в настройках.
8. **Одна "главная кнопка" на экране:** заливкой цвета акцента, остальные — контуром или текстом.
9. **Шрифт:** оставить системный, но заголовки сделать крупнее и жирнее (как в "Статистике" и Telegram) —
   больше "воздуха".
10. **Значок приложения:** проверить, что он хорошо смотрится на мятном фоне и в тёмной теме (монохромная иконка уже есть).

## 7. Анимация логотипа и иконки ✅

Черновик: **`docs/design/TYB-logo-animation.html`** — открыть двойным щелчком в браузере.
Там же набор иконок и плавающая панель, где можно переключить светлую тему и стекло.

### Вариант А ✅ (утверждён вместе со звуком, ~2,5 с)
1. Появляется тёмный скруглённый квадрат (лёгкое увеличение).
2. Белыми линиями "рисуются" две половинки мозга от центра наружу, затем извилины.
3. Зелёная стрелка обегает мозг по кругу — звук "вжух" (растёт вместе со стрелкой).
4. Остриё стрелки "выскакивает" с пружинкой — мягкий "дзынь".
5. Короткое зелёное свечение вокруг и всё замирает.
Звук сделан без файлов, прямо в браузере; для приложения запишем/подберём такой же короткий звук (до 1 с).

### Другие варианты 💡
- **Б "Перезагрузка мозга":** готовый логотип, стрелка делает один быстрый оборот как кнопка "обновить",
  мозг в конце слегка "вздыхает" (увеличился и вернулся). Короче (~1 с) — подходит для заставки при каждом запуске.
- **В "Собраться":** извилины разлетаются точками и собираются в мозг, затем стрелка. Эффектнее, но дольше — для сайта.
- **Огонёк серии:** иконка пламени при продлении серии вспыхивает и чуть покачивается.
- **Фокус:** при старте фокуса стрелка из иконки делает оборот и превращается в обратный таймер.

### Где показывать
- **Сайт / страница в Google Play** — вариант А или В, целиком, со звуком по нажатию.
- **Первый запуск приложения** — вариант А перед помощником по разрешениям, кнопка "Пропустить".
  Звук только если телефон не на беззвучном.
- **Обычный запуск** — системная заставка Android (Splash Screen) с коротким вариантом Б
  (там анимация должна быть короткой, около секунды), без звука.

### Ещё места в приложении ✅ (все пункты утверждены)
Главная мысль: стрелка по кругу = "время идёт / цикл завершён". Её удобно использовать как индикатор.
- **Экран блокировки:** мозг в центре, стрелка медленно идёт по кругу как таймер до разблокировки.
- **Пауза 30 с перед пропуском:** стрелка заполняет круг за 30 с, в конце — "дзынь" и кнопка "Открыть".
- **PIN создан:** стрелка замыкает круг вокруг галочки — "Готово".
- **Фокус завершён:** экран/уведомление с полной анимацией и звуком.
- **Серия 7 / 30 дней:** анимация + огонёк, маленький праздник.
- ✅ **Загрузка везде — наша стрелка:** вместо стандартного кружка загрузки (и при "потянуть вниз для обновления")
  крутится стрелка из логотипа — дуга, которая чуть-чуть не доходит до конца, с остриём.
  Один общий компонент `ArrowLoader` для всего приложения. Пример — в `TYB-logo-animation.html`.
- **Иконка приложения на рабочем столе** сама не анимируется, но при нажатии на неё заставка Android 12+
  показывает анимированный значок — это почти "оживающая иконка".
Звук — только в важные моменты (первый запуск, фокус завершён, серия), и не на беззвучном.

### Иконки ✅ (утверждены)
Новые иконки в стиле логотипа: одна толщина линий, круглые концы, скругления.
Приложения (4 скруглённых квадрата), Фокус (стрелка по кругу, как в логотипе, + точка), Статистика (столбики),
